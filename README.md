# 📏 ぴったり距離はかり（じぶん専用の名刺カードをつくろう！）

両目（りょうめ）の見え方のちがい（視差：しさ）をつかって、とおくにあるモノまでの距離（きょり）をピタッとはかれる「名刺サイズの定規（じょうぎ）カード」をつくるツールです！

「うでの長さ」や「目と目のあいだの幅（はば）」をあわせることで、**あなた専用（せんよう）のぴったりカード**が作れます。

---

## 🌟 すごいところ

- **じぶん専用（せんよう）サイズ！**
  うでの長さや目の幅にあわせて、目盛り（めもり）の位置を自動で計算します。
- **すきな目盛りを自由にセット！**
  「3m・5m・10m」だけでなく、「8m」や「15m」など、はかりたい距離を自由に選んでカードを作れます。
- **2枚あわせてプリントできる！**
  きほんの白カードと、自分でえらんだ薄いブルーのカスタムカードの2枚が作れます。
- **1クリックでPDF保存！**
  おうちのプリンターで印刷（いんさつ）してすぐに持ち歩けます。

---

## 🔬 なぜ距離（きょり）がわかるの？（しくみ）

右目と左目をこうごにつむぐと、前にある景色（けしき）が**「ちょっとだけ横にズレて」**見えますよね？これが「視差（しさ）」です。

近くにあるモノを見るときほど大きくズレて、とおくにあるモノを見るときは小さくズレます。

このズレかたを計算して、名刺カードの上に「○メートル」という目盛りをつけています。

---

## 🚀 つかいかた

### 1. カードを作って印刷しよう
1. パソコンやスマホで `index.html` を開きます。
2. じぶんの身体のサイズを入力します。
   - **うでの長さ**: うでをまっすぐ伸ばしたときの「目からカードまで」の長さ
   - **目の幅（PD）**: 右目と左目の真ん中の間の距離（小学生の平均はおよそ 55〜60mm です）
   - **カスタム目盛り**: はかりたい距離（例: `3, 5, 8, 12, 20`）をカンマで区切って入れます。
3. **「目盛りを再計算」**を押してプレビューを見ます。
4. **「PDFとして2枚保存」**を押してダウンロードし、プリンターで印刷します。

> **⚠️ 印刷するときのちゅうい**
> 印刷するときは、倍率（ばいりつ）を「100%」または「実際のサイズ」にして印刷してください。「用紙にあわせる」にすると目盛りがズレてしまいます。

---

### 2. つかいかた（外ではかってみよう！）

1. うでを**ピンとまっすぐ**伸ばしてカードを持ちます。
2. 片目（かため）で、**「幅（はば）が約30cmのもの」**（例：A4用紙の長いほうの長さ、大きな図鑑など）の左はしにカードの `0m` を合わせます。
3. 顔やカードをうごかさないようにして、**反対の目**で見なおします。
4. 目標（目じるし）の左はしが、カードのどの数字と重なって見えるかたしかめます。その数字が**そこまでの距離**です！
