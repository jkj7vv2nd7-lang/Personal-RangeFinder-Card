# 視差距離測定名刺カード生成器 (Personal Rangefinder Card Generator)

両眼視差を利用して目視で距離を測定できる「オリジナル距離測定カード（名刺サイズ）」のHTML/JS生成ツールです。  
ユーザー自身の身体サイズ（腕の長さ・瞳孔間距離）や基準とする目標物の大きさに合わせて、最適な目盛り位置をリアルタイムに計算・描画します。

生成されたカードはPDFとして保存・印刷して、名刺サイズ等で持ち運ぶことができます。

---

## 🌟 特徴

- **個人適合型（パーソナライズ）**: 自分の「腕の長さ」や「目の幅（瞳孔間距離）」にぴったり合わせた高精度の目盛りを自動生成
- **リアルタイムプレビュー**: 入力値を変更すると、名刺サイズのカードプレビュー（85.6mm × 53.9mm）が即座に更新
- **文字の重なり防止機能**: 遠距離（目盛りの間隔が狭い部分）でも数字が読めるよう、ラベルの傾き（斜め配置）および高さを交互に自動調整
- **PDF出力対応**: `html2pdf.js` を利用し、1クリックで印刷用PDFを作成可能
- **スタンドアロン動作**: 外部サーバーやバックエンド不要。ブラウザだけで完結

---

## 📐 測定の仕組み（幾何学・視差アルゴリズム）

本ツールは、片目ずつで目標物を見た時に発生する**視差（Parallax）**を利用しています。

### 計算式

カードの左端（$0\text{m}$位置）から各距離 $D\text{ [m]}$ への目盛り位置 $X\text{ [mm]}$ は、以下の公式で算出されます。

$$X \text{ [mm]} = \frac{T \times A}{D \times 100} \times 10$$

- $T$: 基準とする目標物の幅 $[\text{cm}]$ （初期設定: $30\text{cm}$）
- $A$: 目からカードまでの距離（腕の長さ） $[\text{cm}]$ （初期設定: $60\text{cm}$）
- $D$: 測定したい目標距離 $[\text{m}]$

> **Note**: 目盛りの位置 $X$ は「腕の長さ」と「基準目標物の幅」によって決まります。カードの物理幅（約 $75\text{mm}$ 利用可能領域）を超える大きな目盛り（近すぎる距離など）は自動的に除外されます。

## 🚀 使い方

### 1. ツール（Webページ）の使い方
1. `index.html` をブラウザで開きます。
2. 左側のフォームに以下の項目を入力します：
   - **腕の長さ [cm]**: 腕をピンと伸ばしてカードを持ったときの目からカードまでの距離
   - **瞳孔間距離 [mm]**: 左右の目の幅（平均: 男性約64mm、女性約60mm）
   - **基準とする目標物の幅 [cm]**: 日常でよく見る目標物の幅（例: A4長辺 約30cm、ドア幅 約80cmなど）
3. **「目盛りを再計算」**ボタンを押してプレビューを確認します。
4. **「PDFとして保存」**ボタンを押して印刷用PDFをダウンロードします。

### 2. 印刷時の注意点
- PDFを印刷する際は、プリンターの設定で**「実際のサイズ (100%)」**または**「倍率: 100%」**を選択してください（「用紙に合わせる」を選ぶと目盛りサイズがズレてしまいます）。

### 3. 現地での測定手順
1. 腕をピンと伸ばしてカードを持ちます。
2. 片目で目標物（例: 幅30cmのもの）の**左端**にカードの `0m` 目盛りを合わせます。
3. 顔やカードの位置を動かさずに**反対の目**で見直します。
4. 目標物の左端が重なって見えた位置の目盛り数値が、対象物までの概算距離です。
